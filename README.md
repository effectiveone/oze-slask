# OZE Śląsk

Lokalny portal o odnawialnych źródłach energii na Górnym Śląsku.

## Stack
- Astro 4.x (static output)
- Vanilla CSS (Dark Industrial — charcoal + electric blue theme)
- Cloudflare Pages deployment

## Uruchomienie
```bash
npm install
npm run dev
```

## Deploy
Cloudflare Pages: build `npm run build`, publish dir `dist`
